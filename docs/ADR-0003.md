# ADR-0003: Upstreams are design references; no source is vendored

Date: 2026-11-06
Status: ACCEPTED

## Context (evidence, reviewed 2026-11-06)

- ④ `WeirdSky924/agent-handoff-skill` @ `ef01fa9db0ea0aab19141954644a1049da4da795` (MIT): `SKILL.md`, 40 KB `bootstrap_handoff.py`, 25 KB `maintain_handoff.py`, Claude hook templates. Targets Codex/Claude/DSH, `AGENT_HANDOFF_PROTOCOL` marker blocks.
- ③ `aploe/claude-handoff-skill` @ `b6ad33e52c8c72f95cbafb006b7c7347c34f3ec8` (MIT): four Claude plugin sub-skills (`handoff-write|resume|list|archive`), prompt-only (no executable script), central `~/.claude/handoffs/INDEX.md` index, local-time stamps.
- Both license files are standard MIT, bodies identical (see `THIRD_PARTY_NOTICES.md`).

## Decision

Re-implement the needed semantics in this repo's own core (adapter + shared core). **Do not copy upstream files.** Pin the reviewed SHAs in `upstreams.lock.json` as the semantic baseline; `adoption_scope` records that nothing is vendored.

## Impact table

| Upstream feature | Handling here |
|---|---|
| ④ `AGENT_HANDOFF.md` + `.agent-handoff/` | Preserved read-only; durable truth owner (P3). No overwrite. |
| ④ `AGENT_HANDOFF_PROTOCOL` blocks | Never replaced; we use `UNIFIED_HANDOFF` blocks; dedup plan before touching (AGENTS.md rule). |
| ④ hooks / `handoff-watch.mjs` | Not adopted (executes code on host events). |
| ③ central INDEX.md | Not adopted (global mutable index forbidden); per-session scan only. |
| ③ local-time stamps | Replaced by UTC ISO 8601. |
| ③ `.handoffs/<ts>-slug.md` | Legacy; non-destructive import (P1 migration). |
| ③ Claude-only `/handoff:*` commands | Not claimed for other hosts; common CLI is the entry point. |

## Consequences

- If vendoring is ever needed: separate PR, retain copyright + MIT text per file, bump `adoption_scope`, update notices.
- Upstream HEAD changes trigger an issue only (`scripts/check_upstreams.py`); lock moves only through a reviewed PR.
